# Chainsaw Man Fansite
A Chainsaw Man fansite created as a CSUN COMP 484 assignment. The topic was chosen based on my personal interest in the series.

The site focuses on building the interface primarily with raw HTML and CSS, without relying on frameworks for the core styling. It demonstrates semantic HTML structure, CSS layouts, responsive design techniques, navigation, images and other fundamental web development concepts.
